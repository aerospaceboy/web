## 模型与数值证据

这是本站自行选择的归一化教学模型，不能作为比赛或硬件实测：

```text
y'' + 2 y' + y = u + d
r = 1, y(0) = y'(0) = I(0) = 0
u_raw = Kp (1-y) + Ki I - Kd y'
u = clip(u_raw, -3, 3)
I' = 1-y，输出饱和且误差继续推向该饱和方向时置零；Ki=0 时冻结积分
```

微分作用于输出，理想模型直接使用状态速度；没有加入传感器噪声或微分滤波。连续闭环采用固定步长 0.01 的 RK4，观察归一化时间 0…20；不是原文离散伪代码的逐行执行。可选扰动在 t=10 从 0 变为 -0.3，对比曲线采用相同条件。基础 PID 概念链接至 [密歇根大学 CTMS](https://ctms.engin.umich.edu/CTMS/index.php?example=Introduction&section=ControlPID)，不声称本页对象或预设来自该教程。

最大超调为 `max(0,max(y)-1)*100%`，末端误差为 `abs(1-y(20))`，不把末值称为稳态证明。固定基线为 (2,0,0)，PI 为 (2,1,0)，默认 PID 为 (2,1,1)。增益范围分别 0…12 / 0…6 / 0…6。

`tests/pid-lab.test.cjs` 的独立数值证据：

- 零增益无扰动保持零输出，末端误差为 1。
- P=(2,0,0) 与解析解 `y=(2/3)[1-exp(-t)(cos(sqrt(2)t)+sin(sqrt(2)t)/sqrt(2))]` 全采样比较，误差小于 2e-8，末值接近 2/3。
- 默认 PID 的闭环分母为 `(s+1)^3`，响应与 `y=1+exp(-t)(-1-t+t^2/2)` 全采样比较，误差小于 2e-8；t=4 峰值的超调约为 5.495%。
- 加扰动后的 P 末值接近 `(2-0.3)/3`，t≤10 与无扰动结果完全相同；默认 PID 的 t=20 误差小于 0.002。
- 八个增益范围角点在扰动下均为有限值，控制输出始终在 ±3；积分步长减半后的末值差小于 0.02、超调差小于 1 个百分点。异常参数和无界积分选项会拒绝。

以上是数值模型验证，不是所有增益下的严格稳定性证明或物理系统验收。
