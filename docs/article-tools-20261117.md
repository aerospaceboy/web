# 文章内目录与链接工具

2026-11-17 已通过 Halo 保存、重开回读及公网浏览器检查。

## 已上线的功能

- 文章正文上方新增“复制文章链接”和折叠目录。目录从该文实际 `h2/h3` 生成，不会把项目速览或工具自己的文字作为章节；不足两个章节时不显示目录。
- 目录支持键盘操作。跳转后章节获得焦点，并留出顶部导航的滚动间距；更新当前片段地址时保留 Pjax 的历史状态与标识。Ctrl/Shift 等修饰点击继续使用浏览器行为。
- 每个章节标题旁增加 `#` 链接复制按钮，Clipboard API 返回成功后短暂显示 `✓`，同时提供状态提示。浏览器拒绝复制或不提供该 API 时，显示可选择的只读链接字段，供手动复制。
- 顶部工具优先使用同源、同文章的 canonical，复制时去掉跟踪参数和旧片段。文章链接不带片段，章节链接指向相应标题。
- 唯一的原有章节 ID 保留，包括实际内容中已百分号编码的 ID；复制和跳转再进行一层片段编码。缺失或冲突的 ID 使用标题生成稳定名称，并避开全页已占用的 ID。
- 工具在正文外，章节按钮也从统计中排除；原有桌面侧栏目录继续保留，没有混入按钮的装饰符号。

仅为客户端渐进增强：禁用 JavaScript 时正文和原有服务器内容保持可读，但自动生成的目录及新增锚点需要 JavaScript。没有改写 CMS 正文、添加阅读历史存储或发送新的分析请求。
