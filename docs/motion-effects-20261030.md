# 博客动态特效（2026-10-30）

用户希望加入与 [夏夜流萤](https://blog.cuteleaf.cn/) 类似的动态效果。实看参考站后，确认其特效面板提供樱花开关，首页副标题使用逐字轮播。本站围绕这两点自行实现，并保留既有星云素材及品牌排版；未复制参考站图片、视频或代码。

## 上线效果

- 默认樱花飘落，可切换流萤光点或关闭飘落/光点。桌面固定 22 个节点，手机 10 个节点，不因每次页面跳转累积。
- 首页副标题循环显示原有“写代码，也仰望星空。”及两句简短文案；使用同一个定时器逐字删除和输入。无障碍名称保持原有完整副标题，不逐字触发读屏播报。
- 星云图缓慢平移缩放，品牌文字轻微进入动画。背景离屏后由原有首页观察器暂停。
- 首页侧栏标题改为“阅读与特效”；手机菜单和文章折叠设置也提供氛围模式与“首页打字字幕”开关。原字号与减少动效设置继续使用原存储键。
- 新设置只写入 `ab:motion:v1`；不可用时本次页面仍可调整。未增加网络资源或第三方请求。

装饰层 `aria-hidden` 且 `pointer-events:none`，不改变链接位置，不拦截按钮。粒子使用 CSS 动画，不使用全屏 Canvas 或持续 JS 动画帧循环。窗口隐藏后粒子暂停，字幕停止；首页离屏后字幕停止。系统减弱动效、已有减少动效及节省流量偏好会停止本轮新增动画并保留完整文案。打印时隐藏装饰。

“关闭飘落与光点”只关闭氛围粒子；“减少装饰动效”用于统一关闭动态装饰。每个访客的选择只保存在自己的浏览器。
