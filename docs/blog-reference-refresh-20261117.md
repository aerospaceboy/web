# 博客交互参考补充调研（2026-11-17）

## 结论与边界

本轮建议在现有 PID 入门文章中加入一个**手动调参的教学阶跃响应演示**：读者改变 P/I/D 参数，在同一模型与参考输入下重新计算曲线，结合原文理解参数的作用。优先增加解释技术的能力，而不是继续增加全站装饰组件。

这是针对三个代表站点的定向一手调研，不是“全网”覆盖。检查方式为读取站点当前公开页面及其正文、链接和控件文本；**没有实际操作外站演示，也未做外站性能、帧率、弱网、手机真机、200% 缩放、键盘全流程或无障碍合规测试**。下面将页面事实与本站设计建议分开记录，控件存在不等于其行为已经验收。

工作上下文已明确：本站已有精选项目、导航收拢、动效开关、文章折叠目录/章节链接及服务端 SEO。本轮不重复建议这些功能，也不增加缺少真实内容的新栏目。这个现状来自当前任务交接，不是本轮独立全站审计结论。

## 候选交互：PID 参数小实验

### 内容价值

它承接“P/I/D 分别做什么、如何调参、为什么需要限幅和记录阶跃曲线”等入门问题。读者不必离开文章安装工具，即可在同一假设下观察参数改变后的差异。与 Josh 的同题对照、Nicky Case 的自主实验节奏相呼应；这只说明设计依据，不证明学习成绩或阅读时长会提高。[参考示例](https://www.joshwcomeau.com/animation/css-vs-javascript/)、[参考实验控件](https://ncase.me/sim/)

### 建议首版范围（待实现与验收）

1. **明确模型**：在实验旁显示被控对象方程、初值、参考阶跃、采样周期、时长、控制输出范围及积分处理。可选用归一化一阶对象，例如 `dy/dt = (u - y) / τ`；具体参数由实现确定并写明。不要只显示一组没有单位或模型来源的曲线。
2. **少量可理解的操作**：P/I/D 参数输入与滑块、清楚命名的教学预设、恢复默认值；调整后重新计算同一时间区间。预设是该模型的学习案例，不是通用于电机、机器人或真实装置的推荐增益。
3. **可读的输出**：曲线标明目标值和响应值，并提供最终误差、峰值等文字结果；如展示超调量或调节时间，给出计算定义、观察时长及“未在时窗内稳定”等状态。不得把最后一个采样点直接称为已经证明的稳态值。
4. **准确的解释**：说明参数效果依赖对象、离散算法和限幅，不把“增加某项一定更快/更稳”写成普遍规律；限制异常参数并提示数值不稳定，避免画出截断曲线后仍给出成功结论。
5. **有明确证据边界**：展示“教学数值模拟，非硬件实测”，不关联比赛性能、物理设备安全性或实际控制器验收结果；保留文章原有公式与工程注意事项。

### 实现约束与验收建议（本站建议，不是外站测评结果）

- 使用局部组件，仅在对应文章挂载；不加载新的第三方动效库。计算结果按需重绘，避免为静态阶跃图开启无限逐帧循环。这是控制本功能复杂度与资源消耗的选择，并非未经测量的性能提升结论。
- 原生标签、可键盘操作的输入、可见焦点与数值读数；曲线颜色之外提供图例和文字结果。系统减弱动态效果或本站关闭动效时，参数计算和静态结果仍可用。
- 窄屏与 200% 缩放下控件可换行，图表不遮挡正文；触摸输入有足够空间。PJAX 多次进入/离开文章时不重复挂载、不累积事件监听。
- 至少核对默认情形、零增益、输出限幅和极端参数的结果；核对数值模型与公开显示的方程、积分/微分定义一致。完成后在本站实际检查输入、重置、缩放和路由往返，才可标记“已上线并验收”。
