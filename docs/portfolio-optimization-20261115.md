# 作品展示与阅读优化（2026-11-15）

本轮按网站对标的第一批建议完成实现并在 Halo 保存上线。

## 页面变化

- 首页保留星云、打字字幕、樱花及既有导航，收紧品牌区，加入 AFDX 和智巡未来两张精选项目卡，带详情和适用的 GitHub 链接。
- 项目页保存为原生 HTML 卡片正文，桌面双列、窄屏单列。保留两个项目链接与五个技术方向，增加实现重点和验证范围，不编造本人职责或比赛结论。
- 两篇项目文章提供速览：项目摘要、实现重点、验证范围和资料版本。标题区使用固定深色底，减少浅色封面与主题主色阴影对文字的影响。
- 阅读页面按正文汉字逐字、英文和数字按词计数；排除脚本、样式、按钮和新增速览。时长按汉字 350 字/分钟、英文 200 词/分钟估算，并在提示中说明。FPGA 文章现显示 1,585 字/词、约 5 分钟。
- 默认隐私占位正文替换为浏览器偏好、评论账号、站点维护、外部资源和内容使用说明；清理原有占位分享摘要，项目页也使用精简摘要。

阅读统计属于客户端显示修正；本轮未改 Halo 核心保存的原始统计字段，关闭 JavaScript 时仍由主题原有统计显示。项目页卡片正文则直接保存在 CMS，关闭 JavaScript 仍可读取内容和链接。

## 实现与发布

`config/site.json` 的 `featured_projects` 是首页、项目索引和文章速览共用的资料。`blog_tools/portfolio.py` 校验目标和转义内容，构建 `build/projects-body.html`；`customization/portfolio.js` 安装首页卡片与阅读增强，并处理 Pjax 重复调用。

仅更新既有 `aerospaceboy-global-style` 和 `aerospaceboy-mobile-navigation-script` 两个块，其余注入保留。注入脚本仍通过 Thymeleaf 开始标记检查。未更换主题或安装插件。

CMS 发布时会过滤 `article`/`section` 包裹标签；公网回读发现后，项目页改用保留 class 的 `div` 卡片容器。最终服务端输出核对到两张完整卡片和方向区域。

主题在窄屏 `#post-info::after` 中添加主色 inset shadow，会覆盖元数据；本轮移除该层。实际窄屏标题区从调研时的 600px 降至约 394px（实际 CSS 视口 300px 宽），日期和阅读信息可见。
