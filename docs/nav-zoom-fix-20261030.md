# 顶部导航缩放修复（2026-10-30）

用户截图中的站点名、菜单和右侧图标在浏览器放大后重叠。已在真实公网首页复现：1200 CSS 像素时菜单同时越过品牌区和工具区边界，1280–1920 的部分宽度也挤占右侧工具区。

## 原因与修复

当前 Hao 1.7.3 的 `main.js` 用站点名、菜单和搜索按钮的宽度决定 `hide-menu`；没有计入完整右侧工具区。主题还将菜单和工具区绝对定位，菜单文本使用较大字距。即使整体剩余空间不足，菜单仍可能保持展开并覆盖其他区域。主题对 768 的 JS/CSS 边界处理也不一致。

修复仅使用本仓库 CSS 与组合脚本，不改 Halo 核心或主题安装包：

- 品牌、菜单、工具区使用同一行的正常布局，各自保留空间；减小主菜单多余字距，文字保持原字号和单行。
- `header-layout.js` 计算整个工具区和菜单的实际宽度，空间不足时自动收起；排除收起按钮自身宽度，避免切换模式反复振荡。
- 通过 ResizeObserver、字体加载事件和 resize/Pjax 重新计算，脚本重复执行只保留一套观察器和监听器。
- 紧凑模式隐藏的原菜单设置 inert/aria-hidden，并取消隐藏过程的延迟，避免视觉重叠或隐藏链接仍参与键盘焦点。
- 放大后继续使用主题原生侧栏，侧栏补充导航不再局限于 768 以下，保留全部 11 个菜单入口。
- 禁用与主菜单共用位置的浮动页面标题，避免滚动后的标题再次叠在菜单上。
